# brainCloud Lua examples

Examples for the [brainCloud Lua SDK](https://github.com/getbraincloud/braincloud-lua), built
with [LÖVE](https://love2d.org) 11.4+.

| Example | What it shows |
|---|---|
| [CursorParty (RelayTestApp)](RelayTestApp/README.md) | Cross-client real-time demo: lobbies, room server, relay, RTT chat, leaderboards. Open `RelayTestApp/RelayTestApp.code-workspace` in VS Code to get started. |
